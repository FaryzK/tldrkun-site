Privacy policy

For the Weirdly publishing app. Last updated 12 November 2026.

The Weirdly publishing app is a private tool that the owner of the Weirdly YouTube channel uses to publish that channel's own videos. It is not offered to the public. This page explains what it does with Google user data.

What it accesses

With the channel owner's permission, given on Google's sign-in screen, the app uses the YouTube Data API to manage the owner's YouTube channel. It uses that access only to upload the channel's videos, set their titles, descriptions, tags and thumbnails, set when they are released, and read the channel's name to confirm it is posting to the right channel.

How it stores data

The sign-in token Google issues is kept only on the channel owner's own computer. The app keeps no other Google user data, has no server or database, and does not collect any information about viewers of the channel.

Sharing

The app does not sell, share or transfer Google user data to anyone, and does not use it for advertising or to train any model. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the token from the owner's computer removes everything the app keeps.

Contact

Questions about this policy can be sent through the Weirdly channel on YouTube.
